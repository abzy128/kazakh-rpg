# Credits

## Code

All code was written during the hackathon. Open-source dependencies are listed in `package.json` and used under their licenses.

## Art

- **3D models:** procedural, made in code (`src/game/world/models.tsx`). No third-party models yet.
- **Portraits, title art and the end-of-day painting:** generated with Meta Muse Image (`scripts/gen-art.ts`).
- **Yurt ornament and lattice textures:** drawn procedurally on a canvas.

## Voices

- Soniox Text-to-Speech, or the browser's speech synthesis when Soniox isn't configured.

## Cultural content

`src/content/aul-18c/customs.md` was written for this project in our own words. It's a draft that a native speaker must review.

When adding third-party assets, record the title, author, source URL, license and retrieval date here, and keep the license file. Quaternius files: use the CC0-labelled Poly Pizza or OpenGameArt copies, not new downloads from quaternius.com, whose license since Aug 2026 forbids redistributing the files.
